# Leroy Merlin — eMerch Toolkit · Módulo Descripciones

Repositorio de trabajo del **módulo de Descripciones** del eMerch Toolkit: generación masiva de descripciones de producto cruzando guía de estilo, atributos por SKU (CSV) y un prompt personalizable, con salida en CSV listo para Mirakl.

## Contenido

| Archivo | Descripción |
|---|---|
| [wireframe_descripciones.html](wireframe_descripciones.html) | Prototipo/wireframe interactivo del módulo (flujo completo de pantallas). |
| [ESTADO_MODULO_DESCRIPCIONES.md](ESTADO_MODULO_DESCRIPCIONES.md) | Estado del trabajo y contexto persistente entre sesiones. Actualizar al final de cada sesión relevante. |
| [PROPUESTA_RECORTES_DESCRIPCIONES.md](PROPUESTA_RECORTES_DESCRIPCIONES.md) | Análisis de funcionalidades candidatas a simplificar o eliminar (sin decisiones tomadas). |

## Flujo del módulo

Selección de guía → selección de modelo → subida/validación de CSV → configuración de prompt → vista previa → generación masiva → descarga.

## Cómo ver el prototipo

Abrir [wireframe_descripciones.html](wireframe_descripciones.html) directamente en el navegador.
